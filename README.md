# PolyHorn

## Usage

The mod adds two horns:
  - The **Horn of Origin**: A horn that, when blown, teleports the player to their spawn point.
  - The **Horn of Return**: A horn that, when blown, teleports the player to a previously set location.
    To set the location, the player must shift + right-click with the horn in hand.
    The location will be saved for that player and can be used later.

The mod is exclusively server-side.

## Commands

- /polyhorn help 
    - Displays a list of available commands and their descriptions.


- /polyhorn config \<subcommand> \[args]
    - Manage the PolyHorn mod configuration.


- /polyhorn give \<players> \<hornType>
    - Give a horn of a specific type to one or more players. (admins only).
